# SIH 26189 Synthetic Criminal Network Dataset

All records are fictional and generated for software development, testing, evaluation and demonstration.
Do not use as real-world criminal intelligence.

`ground_truth.csv` contains planted network memberships and anomalies. Keep it separate from the detection pipeline during evaluation.

Planted patterns:
- 5 synthetic networks
- bridge individuals
- circular transaction flow
- transaction layering chain
- communication spike
- aliases
- unstructured intelligence reports
- cross-source entity relationships
